# git y github
estos son comandos que utilizaremos durante todas las clases para guardar nuestros proyectos de github

---


## 1. ver el estado del proyecto


´´´ bash 

git status
´´´


muestra los archivos que fueron modificados 


---


## 2. Agrega los cambios 

´´´ bash

git add
´´´

agrega los archivps modificados 

>el punto (´.´) significa **todos los archivos**


---


## 4. crear un commit 

´´´ bash 

git comit -m" descripcion de los cambios"
´´´


guarda nueva version  del proyecto.

> ´-m´permite escribir un mensaje que escriba los cambios realizados 


---


## 4. subir los proyectos a Githab

´´´bash
git push origen main 
´´´

sube el proyecto a github.

-´origin´-repositorio remoto 
-´main´-rama principal
